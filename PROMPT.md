# Составной промпт

Создай CLI-инструмент на Python для генерации PDF-чека из CSV-файла и HTML-шаблона с помощью WeasyPrint и Jinja2.

Требования к проекту:

1. При первом запуске скрипт использует папки `data`, `templates` и `output`, расположенные рядом с ним.
2. Скрипт читает CSV в кодировке UTF-8. Обязательные колонки: `product`, `price`, `qty`.
3. Проверь каждую строку: название товара не должно быть пустым, цена не может быть отрицательной, количество должно быть целым числом больше нуля. Покажи пользователю понятное сообщение при ошибке.
4. Подставь товары в HTML-шаблон с плейсхолдерами Jinja2, рассчитай сумму по каждой позиции и общую сумму чека без ошибок округления денежных значений.
5. Поддержи кириллицу и длинные названия товаров, которые не должны ломать таблицу.
6. Сохрани PDF в папку `output` и по умолчанию автоматически открой его системной программой.
7. Скрипт должен работать в Windows, macOS и Linux. Для открытия файла используй подходящую системную команду.
8. Если скрипт запущен без аргументов в интерактивном терминале, покажи нумерованные списки доступных CSV-файлов и HTML-шаблонов. Дополнительно поддержи аргументы `--data`, `--template`, `--output`, `--receipt-number`, `--customer` и `--no-open`.
9. Добавь тестовый CSV минимум с пятью строками, аккуратный HTML-шаблон, `requirements.txt`, понятный `README.md` и автоматические тесты.
10. Не используй внешние веб-ресурсы в шаблоне: PDF должен генерироваться без подключения к интернету.

После создания проекта запусти тесты, сгенерируй контрольный PDF и проверь, что кириллица, суммы и вёрстка отображаются корректно.
