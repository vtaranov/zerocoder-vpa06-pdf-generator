# Домашнее задание VPa06. PDF-чек-мейкер

## 1. Базовое задание

Я создал CLI-приложение на Python, которое читает тестовые товары из CSV-файла, проверяет данные, подставляет их в HTML-шаблон и формирует PDF-чек в папке `output`. В шаблоне используются плейсхолдеры `{{ product }}`, `{{ price }}` и `{{ qty }}`. По умолчанию готовый PDF автоматически открывается системной программой; для автоматизированной проверки предусмотрен флаг `--no-open`.

В тестовом CSV находятся пять товарных позиций. Для корректной обработки денег используется `Decimal`, поэтому итоговые суммы рассчитываются без ошибок двоичного округления. Кириллица и длинные строки поддерживаются стилями HTML-шаблона.

### Файлы проекта

- `pdf_generator.py` - CLI-скрипт;
- `templates/receipt.html` - HTML-шаблон;
- `data/products.csv` - тестовые данные;
- `output/sample_receipt.pdf` - контрольный результат;
- `PROMPT.md` - использованный составной промпт;
- `OFFER.md` - текст оффера;
- `tests/test_pdf_generator.py` - автоматические тесты;
- `README.md` - инструкция по установке и запуску.

## 2. Использованный составной промпт

Полный текст запроса сохранён в файле `PROMPT.md`. В нём зафиксированы бизнес-логика, структура проекта, проверка данных, обработка кириллицы и длинных строк, кроссплатформенное открытие PDF, параметры CLI и требования к тестированию.

## 3. Творческое задание: оффер

Автоматизирую создание PDF-документов для вашего бизнеса: чеков, счетов, актов, сертификатов и отчётов. Настрою генератор под ваш фирменный шаблон и привычный источник данных - CSV, JSON или выгрузку из CRM. Готовые документы создаются за секунды, а автоматическая проверка данных снижает риск ручных ошибок. Решение работает локально на вашем компьютере и при необходимости может быть расширено до desktop-приложения или Telegram-бота.
## 4. Проверка

Проект проверен автоматическими тестами и контрольной генерацией PDF. Контрольный чек содержит пять позиций и итоговую сумму 7 650,00 ₽. Кириллица, таблица, перенос длинных названий и итоговая сумма дополнительно проверены по отрендеренному изображению страницы.
